# Pratap IT Support Lab

A practical IT support troubleshooting simulator built as a technical portfolio project.

## What it does

- Realistic service-desk ticket queue
- Windows, networking, Microsoft 365, Active Directory, hardware and security labs
- Simulated command-line troubleshooting
- Decision scoring with safe vs risky actions
- Persistent browser progress using localStorage
- Practical skill matrix based on completed labs
- Interview-ready evidence generated from solved tickets
- Markdown evidence export
- Challenge mode that hides hints
- Responsive desktop and mobile interface

## Current scenarios

1. APIPA / DHCP failure
2. Slow Windows workstation
3. Outlook authentication after password reset
4. Active Directory account lockout
5. Local print queue failure
6. Unexpected MFA prompts
7. DNS resolution failure
8. Mapped-drive permissions
9. Teams microphone issue
10. New starter file-share access
11. VPN route failure
12. BitLocker recovery

## Deployment

The application is a static Next.js 16 export and deploys automatically to GitHub Pages from the main branch.

Live site:

https://pratapkc6-bit.github.io/job-intelligence-system/

## Purpose

The project is designed to demonstrate troubleshooting process, technical reasoning, safe support practices, documentation and interview communication rather than just listing skills on a resume.
